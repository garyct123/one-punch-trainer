# ONE PUNCH TRAINER｜一拳超人 AI 健身教練

每天早上打開手機，按「開始今日訓練」，App 會像私人教練一樣帶你完成：
**動態暖身 → 一拳超人五輪循環 → HASfit HIIT → 緩和伸展 → 成果摘要**。

React + TypeScript + Vite + Tailwind 製作的手機 PWA。不需登入、不需伺服器、不使用任何付費 API，資料存在裝置的 IndexedDB。

---

## 安裝與啟動

需要 Node.js 18 以上（開發時使用 Node 24）。

```bash
cd one-punch-trainer
npm install
npm run dev        # 開發模式，終端機會顯示 Local 與 Network 網址
npm test           # 執行單元測試
npm run build      # 產生正式版到 dist/
npm run preview    # 預覽正式版（PWA / 離線功能要用這個測）
```

### 在 iPhone 上使用

PWA 的「加入主畫面」與離線功能需要 **HTTPS**（localhost 除外）。三種方式擇一：

1. **部署到免費靜態主機（推薦）**：把 `dist/` 資料夾拖到 Netlify Drop（app.netlify.com/drop），或用 GitHub Pages、Cloudflare Pages、Vercel。專案用相對路徑（`base: './'`），放在任何子路徑都能運作。
2. **同一個 Wi-Fi 先試用**：`npm run dev` 後，用 iPhone Safari 開終端機顯示的 Network 網址（如 `http://192.168.x.x:5173`）。可以操作所有功能，但 HTTP 下無法離線、Service Worker 不會啟用。
3. **電腦 Chrome**：直接開 `npm run preview` 的網址，網址列右側可「安裝」。

### 加入 iPhone 主畫面

1. 用 **Safari** 開啟 App 網址
2. 點下方「分享」按鈕（方框加箭頭）
3. 選「加入主畫面」→「新增」
4. 從主畫面圖示開啟，會以全螢幕 App 模式執行，菜單與計時器可離線使用

### 訓練流程的設計原則

- **次數動作一定要你按「完成」**，計時到了也不會自動記成完成。按完成時會帶入目前畫面上的「實際次數」（預設為目標下限，可用 +／− 調整），結束後的摘要頁還能逐組修正。
- **計時以時間戳計算**，不靠 `setInterval` 累加秒數。切到別的 App、鎖螢幕或重新整理後回來，倒數會自動校正，訓練進度不會消失（每一步都即時存進 IndexedDB）。
- 早晨循環：同一輪動作之間有 15 秒轉換（可改），每輪結束休息 60 秒（可改為 30/45/60/90）。
- 計時型動作（平板、側平板）倒數結束會響鈴並提示「確認完成」，仍要你按完成。側平板左右各一個計時。
- 中途結束：只保存實際按過完成的組數，沒做的不會變成完成紀錄。

### 身體檢查與恢復

每次開始早晨訓練前會問：昨晚睡幾小時、精神 1–5、痠痛 0–10、有沒有頭暈胸痛等不適。

- 回答「有不適」→ 顯示**停止運動與就醫提醒**，不會開始訓練。
- 睡眠 < 6 小時、精神 ≤ 2 或痠痛 ≥ 7 → **推薦恢復版**，HIIT 改為低強度；你可以選擇仍用原菜單（HIIT 仍是低強度）或今天休息。
- App 不會把高強度訓練當成每天必須完成的任務。

### 90 天進階

- 以首次設定的開始日期為 Day 1，自動算出第幾天、第幾週與目前階段（熟悉期 → 微幅進階 → 漸進增量 → 強化挑戰 → 第 13 週減量檢測）。
- **日曆進入下一週不會自動加量。** 第 3 週起，若近 14 天完成率 ≥ 80%、平均睡眠 ≥ 6 小時、平均痠痛 ≤ 5、平均精神 ≥ 3、沒有回報不適，首頁才會出現「可以考慮升級」，**要你按「確認升級」才套用**（預設週二、週五的伏地挺身與深蹲每組 +1 下）。覺得太硬可以隨時降回。
- 所有門檻、進階日、每次加幾下、上限、第 13 週減量輪數都可在「設定 → 進階規則」修改。

### 星期六胸／背輪替

以開始日期之後的第一個星期六為「胸部週」（可在設定改為背部週），之後隔週輪替。背部週是輕重量划船與反向飛鳥，不做高強度背部第二訓。

### 影片

- HASfit HIIT 影片（`o00uuJStrco`）已於 2026-10-26 透過 YouTube oEmbed 確認存在，標題與作者相符，標示為「已驗證影片」。HIIT 步驟會顯示封面、開啟 YouTube、官方說明連結，看完回到 App 自己按「HIIT 已完成」並可調整實際分鐘數。
- 其他動作**沒有逐一驗證特定影片**，因此使用明確標示為「YouTube 搜尋（未驗證）」的搜尋連結，不捏造影片網址。在動作庫貼上你喜歡的影片網址後，會標示為「自訂連結」。
- 所有網址統一在 `src/data/exercises.ts` 管理。

### 備份

設定 → 資料備份：

- **完整備份 JSON**：所有設定、課表、動作庫、紀錄；匯入會取代目前資料。
- **訓練 CSV**：每組一列（日期、動作、輪次、目標、實際、狀態、重量）。
- **每日紀錄 CSV**：體重、腰圍、睡眠、精力、痠痛、備註。
- CSV 可以用 Excel 開啟，也能重新匯入（自動辨識檔案類型）。

## 專案結構

```
src/
  types.ts              所有資料模型
  data/
    exercises.ts        動作庫（影片網址集中管理）
    plans.ts            七天早晨菜單、晚上健身房菜單
    defaults.ts         預設設定與初始資料
  engine/
    workout.ts          Guided Workout Engine（純函式狀態機）
    program.ts          Day/Week、階段、每日菜單、星期六輪替、恢復判斷、升級評估
    fasting.ts          16:8 斷食計算（支援跨午夜）
    stats.ts            完成率、次數統計
    engine.test.ts      引擎單元測試
  lib/
    time.ts             台北時區（UTC+8）工具
    storage.ts          IndexedDB（失敗時退回 localStorage）
    backup.ts           JSON / CSV 匯出匯入
    backup.test.ts      備份單元測試
    voice.ts            語音、提示音、震動、螢幕常亮
  store/AppContext.tsx  全域狀態與自動保存
  pages/                七個主要頁面
  components/           UI 元件、倒數環、SVG 圖表
```

課表全部是結構化 TypeScript 資料，UI 元件內沒有寫死菜單。

## 已知限制

- **iPhone 鎖螢幕或切到背景時**，Safari 會暫停 JavaScript，計時、語音、提示音都會停。回到 App 後時間會依時間戳校正，但**鎖屏期間不會播報**。訓練中 App 會嘗試保持螢幕常亮（iOS 16.4 以上支援 Wake Lock）。
- iPhone 第一次語音需要使用者點擊才會啟用；App 在你按「開始」時會先解鎖。若裝置沒有中文語音，只會有提示音與畫面提示。iPhone 不支援震動。
- App 無法偵測 YouTube 影片是否播完，HIIT 完成要自己按。
- 動作教學影片除了 HASfit 之外都是搜尋連結，不是精選影片。
- 資料只存在這台裝置。清除 Safari 網站資料或刪掉主畫面圖示可能讓資料消失，請定期匯出 JSON 備份。不同裝置之間不會同步。
- 休息倒數到期的自動前進只在訓練畫面開啟時執行；縮小訓練畫面後再打開，會依時間戳補上。
- 本 App 不提供醫療建議。曾長期睡眠不足或有心血管疑慮，開始新訓練前請諮詢醫師。
